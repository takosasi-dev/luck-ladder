# LuckLadder

ブラウザで開くだけで遊べる、トランプのハイ&ロー。次の札が今の札より大きいか、小さいか、同じ数字かを当てて、当てた点を「確保」するまで積み上げます。同じ札で、ブラックジャックとビデオポーカーも遊べます。

**▶ 開く: https://takosasi-dev.github.io/luck-ladder/** (インストール不要)

> **v0.4.0(開発中)。** 1 人用(ラン・今日の山札・実績・記録・コレクション)と、ブラックジャック・ポーカーを遊べます。対戦(2〜4 人)は試験中で、つながらない回線があります。調整値は、まだ人に遊んでもらって決めた値ではありません。変更の履歴は [CHANGELOG.md](CHANGELOG.md) にあります。

- エンジン: Godot 4.7.2(GDScript、Compatibility レンダラー、Web 書き出し)
- 対応(予定): デスクトップの Chrome・Edge・Firefox、スマホの Chrome(Android)・Safari(iOS)。スマホの実機で確かめたのは、iPhone の Safari での対戦だけです
- 本物のお金は賭けません。ブラックジャックとポーカーで賭けるのは、ゲームの中の「持ち点」だけです(買えません)
- 記録はブラウザの中にだけ残ります

## 遊び方

- 山札 52 枚を 1 枚ずつめくります。次の札が今の札より **大きい(HIGH)**、**小さい(LOW)**、**同じ数字(同じ)** のどれかを当てます。A がいちばん小さく、K がいちばん大きい。
- ボタンの `+356` は、当たったときにもらえる点です。当たりにくい側ほど大きくなります。
- 当てた点は「ポット」に貯まり、**確保** を押すまで自分の点になりません。外すとポットは 0 になり、ライフが 1 減ります。
- 連続で当てるほど倍率が上がり、3 連続ごとにライフが 1 戻ります。確保すると連続は 0 に戻ります。
- ライフ(4 個)が無くなったら終わり。山札を最後までめくり切ると「完走」です。

| 操作 | キーボード | タッチ・マウス |
|---|---|---|
| HIGH | ↑ か W | ボタン、または札を上へはじく |
| LOW | ↓ か S | ボタン、または札を下へはじく |
| 同じ | → か D | ボタン |
| 確保 | スペース | ボタン |
| 一時停止 | Esc | 左上のボタン |

音量(BGM と効果音は別々)、演出の強さ、めくりの速さ、残り札の表示は「設定」で変えられます。

## 今日の山札

「今日の山札」は日付で決まり、同じ日なら誰でも同じ並びです。何度でも遊べますが、記録・実績・共有テキストの「初回」に残るのは、その日の 1 回目だけです。結果画面の文字をコピーして貼れば、得点を比べられます。

```
LuckLadder 今日の山札 No.316 (2026-11-12) 初回
1,148点 / 6枚 / 最大1連続
https://takosasi-dev.github.io/luck-ladder/
```

## 対戦(試験中)

2〜4 人が、同じ並びの山札を、それぞれ自分の画面で同時に遊びます。制限時間(2 分・3 分・5 分・なし)のうちに確保した得点で順位が決まります。ルールは 1 人用と同じで、相手の得点・ライフ・めくった枚数が画面に出続けます。

つなぎ方(サーバーを使わず、ブラウザどうしを直接つなぎます):

1. 部屋を作る人(ホスト)が、タイトルの「対戦」→「部屋を作る」→ 空いた席の「招待を作る」→「招待をコピー」を押し、URL を友だちに送ります。
2. 友だちがその URL を開いて「参加する」→「返事をコピー」を押し、URL をホストに送り返します。
3. ホストが、届いた URL を **部屋を開いているのと同じブラウザ** で開きます。席に相手の名前が出たら接続済みです。
4. ホストが「はじめる」を押すと、3 秒後に全員が同時に始まります。

知っておいてほしいこと:

- **招待と返事の URL には、あなたの IP アドレスが入ります。** つながった相手にも、互いの IP アドレスが見えます。知っている人にだけ送り、公開の場には貼らないでください。
- **つながらない回線があります。** 中継のサーバーを置いていないので、学校や会社のネットワーク、一部の集合住宅やモバイル回線では、つながらないことがあります。Wi-Fi とモバイル回線を替えると、つながることがあります。確かめたのは、PC の Chrome と、モバイル回線の iPhone の Safari の組み合わせだけです。
- **不正への対策はありません。** 山札の並びは全員の端末に配られ、相手の得点は届いた値をそのまま表示します。友だちどうしで遊ぶためのものです。
- 招待と返事は、作ってから 2 分で期限が切れます。切れたら「作り直す」を押してください。
- 対戦中にブラウザを隠したり、別のアプリに切り替えたりすると、相手からは「切断」に見えます。
- 相手の接続先を調べるために、`stun.l.google.com`(Google の公開の STUN サーバー)に問い合わせます。部屋を作るか参加するまでは、この通信はしません。

## ブラックジャックとポーカー

タイトルの「ブラックジャック」「ポーカー」から遊べます。賭けるのは、ゲームの中の「持ち点」です。

- 持ち点は 1,000 点から始まり、2 つのゲームで共通です。ブラウザの中に残ります。
- 賭ける点を 10・50・100・500 から選んで「配る」を押します。賭けた点は、その時点で持ち点から引かれます。
- 持ち点が 10 点未満になったら、1,000 点に補充されます(回数の制限はありません。補充した回数は「記録」に出ます)。
- 山札は、勝負のたびに 52 枚を切り直します。
- この 2 つのゲームの結果は、実績・称号・コレクションの解放には数えません。「記録」の画面にだけ残ります。

### ブラックジャック

合計を 21 に近づけて、ディーラーより大きければ勝ちです。2〜10 は数字のとおり、J・Q・K は 10、A は 11(21 を超えるなら 1)と数えます。

- **ヒット**: 1 枚引く。22 以上になったら「バースト」で負け。
- **スタンド**: 止める。ディーラーは、合計が 17 以上になるまで引きます。
- **ダブル**: 最初の 2 枚のときだけ。同じ点をもう 1 回賭けて、1 枚だけ引いて止まります。
- 戻り: 勝ちは賭けた点の 2 倍、引き分けは賭けた点、負けは 0。最初の 2 枚で 21(ブラックジャック)なら 2.5 倍。
- スプリット、インシュランス、サレンダーはありません。

### ポーカー

5 枚配られます。残したい札を押して「残す」を付け、「交換」を押すと、残さなかった札が 1 回だけ入れ替わります。できた役の倍率 × 賭けた点が戻ります。

| 役 | 倍率 |
|---|---|
| ロイヤルフラッシュ | ×250 |
| ストレートフラッシュ | ×50 |
| フォーカード | ×25 |
| フルハウス | ×9 |
| フラッシュ | ×6 |
| ストレート | ×4 |
| スリーカード | ×3 |
| ツーペア | ×2 |
| J 以上のペア | ×1 |

10 以下のペアは役になりません。ストレートは `A-2-3-4-5` と `10-J-Q-K-A` を含み、`Q-K-A-2-3` のように K と A をまたぐ並びは含みません。

| 操作 | キーボード | タッチ・マウス |
|---|---|---|
| 賭ける点を選ぶ | 1・2・3・4 | ボタン |
| 配る / 交換 | スペース か Enter | ボタン |
| ヒット / スタンド / ダブル | H / S / D | ボタン |
| ポーカーの札を残す・外す | 1〜5 | 札を押す |
| もどる(勝負の途中は押せません) | Esc | 左上のボタン |

## やりこみ

- 実績 35 個(うち 3 個は、達成するまで中身が隠れています)
- 通算の得点で上がる称号 10 段
- 札の裏面 8 種とテーブル 5 種(実績や称号で解放)
- 記録(通算の値と、得点の上位 10 ラン)

## 保存データ

記録はブラウザの中にだけ残ります。ブラウザのデータを消したり、シークレットモードで開いたりすると消えます。「設定」→「保存データ」で、文字として書き出し・読み込みができます。同じブラウザの 2 つのタブで同時に遊ぶと、後から書いた方の記録が残ります。

## 手元で動かす

Godot 4.7.2 で、このフォルダを開きます。テストはヘッドレスで回せます。

```
godot --headless --import
godot --headless --script res://tests/run_tests.gd
godot --headless --export-release "Web" build/web/index.html
```

`main` に push すると、GitHub Actions がテスト → Web 書き出し → GitHub Pages への配置を行います。テストが 1 件でも落ちたら配置しません。

効果音と BGM は、スクリプトで作った物をコミットしてあります。作り直すときは Python 3 で次を実行します(BGM は ffmpeg が要ります。PATH に入れるか、環境変数 `FFMPEG` で場所を渡します)。

```
python tools/gen_sfx.py
python tools/gen_bgm.py
```
